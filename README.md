# Suraj Kumar Rawani — Portfolio

Bold red/black portfolio matched to your reference reel, filled with resume + GitHub content.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Add your photo

1. Save your photo as `web/public/photo.jpg`
2. In `web/src/data.js`, set:

```js
photo: "/photo.jpg",
```
